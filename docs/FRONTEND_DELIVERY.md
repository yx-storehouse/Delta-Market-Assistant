# 前端交付记录

当前交付为 2026-10-05 的 0.5 石墨深色 UI，入口为 `dist/RelinkStudio/RelinkStudio.exe`，最新说明见 `WIN11_DARK_UI.md`。下文保留 0.1 初版的历史记录，不是当前验收计数。

日期：2026-10-04。版本：0.1.0 frontend preview。

## 本轮实际完成

- C++17 / Qt 6.8.3 Widgets 原生 Windows x64 应用，完成编译和运行库打包。
- 七个页面：工作台、我的关注、自动任务、价格中心、运行统计、运行日志、设置。
- 本地关注管理、搜索筛选、任务增删改和条件校验、配置导入导出、CSV 导出。
- 独立模拟运行和暂停，模拟计数与日志联动。
- QPainter 绘制图标和曲线，无需外部图片和 QtCharts。
- 小窗口使用页面滚动，不压缩到控件重叠。

## 已观察的验收结果

测试程序使用 Qt offscreen/QCoreApplication，没有创建前台测试窗口或调用系统键鼠。
发行包在移除 SDK PATH 的子进程中启动并完成 33 项界面断言；数据模型完成 48 项断言。

重点覆盖：

- 七页导航和离屏 PNG 输出。
- 关注搜索、空结果、关注勾选和品项价格切换。
- 任务空名称／价格逆序拒绝、新增、编辑和确认删除。
- 配置 JSON 完整往返、非法输入事务拒绝、原配置损坏后原文件保留。
- 编辑已完成任务后重置该任务模拟进度，累计演示统计保留。
- 模拟开始／暂停幂等、数量上限、所有任务完成后停止。
- CSV 标识与公式前缀转义。
- 1180×820 紧凑窗口离屏渲染，以及 1440×960 页面渲染。
- `--validate-config=path` 等号参数仍走离屏分支。

详细命令、退出码和字面输出见 `artifacts/VERIFICATION.txt`、`artifacts/delivery_test_results.json`。

## 真实数据接入状态

本版本仅是前端与本地数据模型。关注列表、价格曲线和模拟结果都不是实时游戏数据。
没有接入画面采集、OCR、市场请求、游戏进程读写、系统输入、购买或交易结果确认。
下一阶段可以把模拟数据提供器替换成页面观察模块，保持界面与任务配置层分离。

## 用户前台约束

用户提出“先做前端，前台用于其他工作”之后，本轮开发没有继续切换或控制游戏。
所有后续测试均在离屏模式执行。发行程序没有为展示效果而自动打开；由用户自行打开。

## 配置修改与回滚验证

本轮另保留一个专门的测试配置副本：第一条任务 `maxPrice:650→700`、`quantity:3→4`。
该副本不是用户默认配置，不改变游戏或原助手程序。
应用自身分别验证基线、修改副本和回滚副本；回滚测试仅恢复另一个测试副本，正式修改样本保持修改状态。

四个记录文件为 `artifacts/MODIFIED_FILE.json`、`artifacts/DIFF_FILE.diff`、`artifacts/VERIFICATION.txt`、`artifacts/ROLLBACK.sh`。
