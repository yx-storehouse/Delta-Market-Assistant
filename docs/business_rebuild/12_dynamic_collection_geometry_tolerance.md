# 动态收藏卡片的轴向观测误差

2026-10-07。灰色未选中卡片与白色选中轮廓的边缘检测存在不同的横向误差；重新绑定使用有限轴向容差，而不是修改或补造实测坐标。

## 实测依据与判定

证据来自 `artifacts/collection_all_rules/run_03/session.json` 最后的选择动作和新帧回读。结构化复核保存在 `artifacts/collection_all_rules/geometry_tolerance_review.json`，包含原记录的 SHA-256、两帧信息、旧判定和新判定。复核只读已有字段，不操作游戏、不保存图像。

| 项目 | 灰色卡片 | 白色选中卡片 |
| --- | --- | --- |
| `bounds`，x/y/宽/高 | `[120,306,871,260]` | `[119,304,866,264]` |
| `fields_bounds` | `[121,523,869,42]` | `[120,525,864,42]` |
| 卡片右边界，x + width | 991 | 985 |
| 卡片上边界 | 306 | 304 |

横向右边缘相差 6 px，纵向上边缘相差 2 px。交叠面积占较小卡片面积 **99.3111366%**。旧的横纵统一 3 px 阈值拒绝了这组实际灰/白轮廓，导致主循环将此前处理过的首卡视为未覆盖并再次选择；这不是新物品的证据。

结论：3 px 是初期少量样本的估计，不是业务不变量。当前在已校准的 2560 × 1440 客户区中，将横向上限调整为 8 px：覆盖已测 6 px 差异并保留 2 px 小余量。该值是工程误差预算，不是对所有分辨率、UI 缩放或后续版本的统计保证。

## 当前约束

实现位于 `tests/manual/collection_scroll.py::same_card_geometry`，选择回读、收藏回执和主循环已访问区域比较共用此判定。

| 条件 | 上限或要求 |
| --- | --- |
| 左、右边缘差值 | 各不超过 8 px |
| 上、下边缘差值 | 各不超过 3 px |
| 宽度差值 | 不超过 16 px |
| 高度差值 | 不超过 6 px |
| 卡片矩形交叠 | 不小于较小卡片面积的 98% |
| 字段条矩形 | 同样满足轴向边缘/尺寸约束，且仍位于各自卡片内部 |
| 输入前坐标租约 | 仍须与当前帧逐字段完全一致；不使用此容差放行旧租约 |
| 回读 | 新帧、唯一真实选中卡片、同帧字段与实测 ROI 绑定 |
| 收藏确认 | 原商品、成色、价格、磨损、任务行一致；新帧金星；原白星/成功提示条件不变 |
| 帧龄、任务快照 | 5000 ms 上限与快照字节哈希锁保持原值 |

实际双列卡片中心间距约 877 px、上下行间距约 275 px，明显超出这里的误差预算。测试仍显式拒绝相邻列、相邻行、横移 9 px、纵移 4 px；小矩形即便位移低于轴向上限，也必须满足 98% 交叠条件。

此函数不改变卡片坐标，不将旧 ROI 移到新帧，不补齐不可见边缘，不推测价格。`clipped_search_region` 半卡继续没有可执行输入点。动态列表刷新可能在同一坐标出现不同物品，因此几何近似本身不是身份确认，收藏确认必须继续经过完整字段匹配。

## 离线复核

在项目根目录运行：

```powershell
python -X utf8 -m unittest discover -s tests/manual -p 'test_collection_dynamic.py' -q
python -X utf8 -m unittest discover -s tests/manual -p 'test_collection_scroll.py' -q
```

新增测试覆盖实际 `run_03` 数值、坐标不变、横纵轴边界、不同卡片和小矩形面积约束。原始 `run_03` 仍保留当时失败状态；离线新策略通过不等于把历史实跑改写为成功。

证据 → 发现 → 修改路径：`run_03/session.json` 的 6 px 横向差异 → 统一 3 px 阈值低于实际观测误差 → `same_card_geometry` 有界轴向判断 → `geometry_tolerance_review.json` 实际包离线重绑通过。
