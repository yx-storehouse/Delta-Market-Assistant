## 真实轨迹移动

`cursor_motion.py` 是独立、纯 Python 的路径规划和执行器；`collection_live_session.py` 的 WindowsBackend 调用它完成鼠标移动。轨迹是确定性的三次 Bézier 曲线，采用 smoothstep 缓入缓出；按距离规划 120–280 ms，不加入随机游走。相同位置不制造无用运动。输入动作只在轨迹到达精确终点、焦点、用户介入、目标位置和采集时效检查通过后发送。

所有现有入口（点击、滚动前定位、悬停、进入时光标定位、会话结束恢复光标）均接入轨迹。模块本身不点击。点击和滚轮发送前再次检查 5,000 ms 观察有效期；收藏还复查冻结快照哈希。中断不重放点星。

### 已复现与修复的本机时钟问题

`layout_probe_03.json`：进入时两次位置更新后遇到 `CURSOR_CLOCK_STALLED`；0 个业务步骤、0 个收藏输入；IDE 恢复。
本机 Python 3.12 的 `time.monotonic()` 使用分辨率 15.625 ms 的 GetTickCount64，短等待不一定推进 tick。默认运动时钟改为 QueryPerformanceCounter 对应的 `time.perf_counter()`；注入粗粒度时钟时允许有限重复 tick，并保留停滞/墙钟总预算和用户输入检查。

`layout_probe_04.json`：连续完成导航与 4 帧滚动校准，14 条运动记录全部完成；实际非零移动约 209–281 ms。每条路径实际更新 18–24 次位置，结束后恢复 IDE 一次。该探针未点击收藏星，不能当成新增收藏证据。图像仅内存采集和工具返回，文件只存数值/OCR/动作记录。
