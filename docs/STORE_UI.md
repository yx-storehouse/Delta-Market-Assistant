# Relink Studio 0.6 · Windows 11 浅色 / 微软商店布局

已解压程序：

```text
C:\Users\Administrator\Desktop\price\dist\RelinkStudio\RelinkStudio.exe
```

直接打开该 EXE，同目录保留 DLL 和 `platforms` 文件夹。开发与验收只使用 Qt offscreen，不弹出可见窗口。

## 配色

用户要求“不要蓝色，按 Win11 同款白灰配色”，并且系统处于浅色模式，所以本版采用 WinUI 3 浅色主题的色值，强调色改为中性近黑：

| 角色 | 值 | 用途 |
| --- | --- | --- |
| Mica 底 | `#F3F3F3` | 标题栏、左侧导航 |
| 内容层 | `#F9F9F9` | 页面底色，左上 8 px 圆角，细边 `#E5E5E5` |
| 卡片 | `#FFFFFF` | 列表行、设置卡片、图表卡片 |
| 文字 | `#1B1B1B` / `#5E5E5E` / `#8A8A8A` | 主文字 / 次要 / 辅助 |
| 强调 | `#1F1F1F`，文字白色 | 主按钮、选中短竖条、开关、输入焦点下划线 |
| 状态 | `#0F7B0F` / `#9D5D00` / `#C42B1C` | 成功 / 注意 / 严重；价格下跌绿、上涨红 |

界面截图验收会检查任务、统计、日志、设置、运行页没有蓝色像素（皮肤插图除外）。

## 窗口结构（对应微软商店）

- 顶部：系统标题栏设为同色 `#F3F3F3`；下方居中搜索框（直接筛选关注列表），右侧导入、导出、帮助和运行状态。
- 左侧导航：图标在上、文字在下；选中项显示白色底板、左侧短竖条和实心图标，并隐藏文字，与商店一致。
- 内容层：比 Mica 略亮的整块区域，只有左上角圆角。
- 控件：按钮和输入框 4 px 圆角，卡片 6–8 px；输入框获得焦点时底边变为 2 px 深色下划线；开关、下拉、数字框使用 Segoe Fluent Icons 图标。
- 字体：Segoe UI + Microsoft YaHei UI，图标 Segoe Fluent Icons。真实 Windows 与离屏验收解析到同一组字体（`RelinkStudio.exe --font-report` 可复核，不创建窗口）。
- 弹窗：任务编辑、删除确认、帮助都采用 ContentDialog 结构：白色内容区加浅灰按钮栏。

背景是应用绘制的静态颜色，不是系统 Mica；控件仍为 Qt Widgets，没有改成 WinUI。

## 原程序功能入口对照

| 原程序“Relink枪皮助手” | 本程序位置 |
| --- | --- |
| 顶部标签“S11新赛季1103” | 运行 → 配置方案 |
| 运行按键 F2 | 运行 → 运行快捷键（F1–F12） |
| 定时 | 运行 → 定时运行（开始、结束时间与开关） |
| 购买延迟(ms) 830 | 运行 → 购买延迟 |
| 动态延迟（跳过抽奖页：开启） | 运行 → 动态延迟（保留原注明“不建议”） |
| 队列已满减延迟：触发 1 次 · 1.0 ms | 运行 → 队列已满时减延迟 |
| 在公示期加延迟：触发 1 次 · 1.0 ms | 运行 → 公示期加延迟（按标题理解为增加延迟） |
| 连续点击 / 点击间隔 | 运行 → 连续点击、点击间隔 |
| 购买量限制 [橙色-紫色-蓝色] | 运行 → 按品级限制购买数量 |
| 刷新界面 / 跳过抽奖页 / 跳过成功页 | 运行 → 挂机设置 |
| 自动收藏模式 / 收藏状态 OSD | 运行 → 自动收藏 |
| 自动收藏-任务配置（启用、皮肤、成色、最大磨损、最低/最高价格、限制量） | 任务页；新增“成色”列与编辑项，皮肤显示为“赛季 | 名称” |
| 优化 | 运行 → 优化（具体项目待确认，暂为入口占位） |
| 记录 | 日志、统计页；运行 → 运行记录 |
| 帮助 | 右上角“?”与运行 → 帮助 |
| 导出 / 导入 | 右上角导入、导出 |

这些参数写入配置文件的 `run_settings`，任务增加可选字段 `condition`（缺省“不限”）。旧配置文件仍可载入并取默认值。前端只保存参数，不连接游戏，不执行点击或购买。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test -Package
python artifacts\store_ui\verify.py
```
