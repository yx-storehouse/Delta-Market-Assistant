## 使用当前任务，而不是历史快照

从仓库根目录执行数据冻结（不会操作游戏）：

```powershell
python -X utf8 tests/manual/collection_run_config.py `
  --config "$env:LOCALAPPDATA\RelinkStudio\RelinkStudio\config.json" `
  --catalog src/assets/catalog/skins.json `
  --output artifacts/collection_live_trial/input/task_snapshot.json
```

本轮路径已经存在，CLI 会拒绝覆盖。后续新运行使用新输出文件名，保留每次配置字节 SHA-256、目录 SHA-256、原导入行与原字段。`source_kind=current_config`；来源 savedValue 哈希保留在每行 `import_source` 中，不能与当前配置哈希混淆。用户扩展目录自动读取配置旁的 `catalog_extensions.json`。

协调器首次读取快照时核对原始字节哈希，后续每次收藏前再核验；文件中途变化即停止。它不会出现“按旧条件导航，却按新文件价格点星”的混用。

## 原业务顺序和执行范围

`tests/manual/run_collection_trial.py` 对照 [BBZPS 原流程](business_rebuild/10_bbzps_first_startup_reconstruction.md) 实现：

1. 当前页面识别；已有商品列表先保留接续信息，商品/赛季未确认时重新检查筛选。
2. 典藏首页先检查关注；空关注独立再读一次，再回首页筛选。已有关注保留；本轮收藏模式不进入其购买处理。
3. 当前赛季正确则不重选；拥有/品阶缺少用户限制时按 `any` 清除已观察到的残留筛选，不从目录颜色推断品质。
4. 在当前目录里按精确名称找商品；缺失时有界滚动目录重新查找，不从本地目录索引猜点击坐标。这一目录滚动分支尚未由本轮实际触发，不能称实机验收通过。
5. 商品标题回读、列表公示/排序检查、S/A/B/C 成色选择与回读。
6. 所选卡片商品、成色、价格、磨损同帧联合匹配；已有金星跳过；新收藏先写 journal，再点星，随后新帧确认同条目及金星变化。
7. 超价按原行为结束当前扫描段；它不证明后续所有价格都单调。继续下一规则、商品和赛季时保留任务顺序，不将未观察尾部标成穷尽。

尚未贯通：卖单列表动态滚动/半行几何、非零限量、不限成色计划、满额专门交接，以及全任务完整实机验收。当前任务的数量均为 0（不限），本轮未静默忽略非零限量。

## 两项执行开销的实际改动

### 连续前台会话

`collection_live_session.py` 提供 `ForegroundSession`，由业务协调器在一个 `with` 范围内连续操作。旧 `run_foreground_batch.py` 仍兼容 20 步/30 秒有限计划；新协调器不再每两条收藏退出、重新前置游戏。

动作前年龄上界为 `max(worker_age, capture_roundtrip + source_age + uncertainty) + 接收后耗时`，包含旧实现漏掉的编码/传输尾段。5,000 ms 门槛保持；journal 写入后、真正输入前再次检查。没有通过放宽过期门槛换速度。

### 单次观察内复用 OCR helper

同一诊断 EXE 中，整帧及多 ROI 共享一个隐藏 PowerShell 会话，按语言缓存 Windows OCR 引擎。每条请求有独立请求/帧/映射关联，helper 释放映射后回执，异常确认进程退出后再释放；原 one-shot 兼容。

这是**单次观察内**的复用。每次 capture 仍启动新的诊断 EXE，尚未成为跨观察长期常驻的完整生产运行时。Qt 的 overlapped stdin 与同步管道显式区分；初版两次超时实验完整保留，没有把失败实验记成优化完成。

合成 OCR 128 项断言及连续多次连读通过，属于合成输入验证。真实游戏性能只看 `run_02_review.json` / `run_03_review.json`；比较口径为明确选卡开始到该条新收藏回读结束，不拿导航总时长除以收藏数充当单条性能。

本轮同口径小样本：原包 9 个稳态新增的中位数 **8.015 秒**；新包 4 个真实新增的时长分别为 **3.422、3.485、3.422、3.469 秒**，中位数 **3.4455 秒**，降低约 **57%**。新包 38 次实际诊断分别只启动 1 个 helper，合计执行 224 次识别；采集本身中位 207.5 ms，完整观察往返中位 1,094 ms。这个结果来自真实游戏，不扩展成所有商品、滚动页面或持续吞吐的保证。
